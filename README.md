# Hridyansh Babu Birthday Invitation

A mobile-friendly Next.js/Vinext digital birthday invitation for Hridyansh Babu's first birthday celebration in Nepal.

## Included

- Opening invitation gate with animated sky, balloons and stars
- Nepali + English invitation copy
- Sanskrit birthday blessing: `जीवेम शरदः शतम् ।`
- First birthday date: 16 September 2026 / 2083 भाद्र 31
- Birth detail: 16 September 2025 / 2082 भाद्र 31
- Live countdown, WhatsApp RSVP and phone contact buttons
- Family-supplied portrait rendered with `next/image`
- Accessible opening transition, reduced-motion support, and responsive layouts
- Countdown ends at the start of 16 September 2026 in Nepal (UTC+05:45); no event time or venue is assumed

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL shown in the terminal. To create a production build:

```bash
pnpm build
```
